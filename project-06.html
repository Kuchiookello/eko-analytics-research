PROJECT 06 • PROGRAMME PERFORMANCE

NGO Programme Performance Review

A programme-analysis case study examining implementation, beneficiary reach, outputs, indicators and evidence for organisational learning and programme improvement.

CASE STUDY OVERVIEW

Using programme evidence to understand performance.

Project 06 demonstrates how programme information can be consolidated and analysed to provide a clearer picture of implementation and performance.

The review framework considers programme reach, outputs, indicators, progress and areas where management attention may be required.


REVIEW QUESTIONS

What the project investigates

  • Is programme implementation progressing as expected?
  • How many beneficiaries have been reached?
  • Which outputs and indicators are performing strongly?
  • Where are performance gaps emerging?
  • What implementation patterns require management attention?
  • What lessons can inform programme improvement?
